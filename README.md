# Currency Note Detection System

A deep learning-based computer vision system for detecting and classifying Indian currency notes using the YOLO object detection framework.

## Features

- Indian Currency Note Detection
- Real-Time Object Detection
- High Detection Accuracy
- Robust Performance under Different Lighting Conditions
- Evaluation on Diverse Test Datasets

## Tech Stack

- Python
- YOLO
- OpenCV
- Computer Vision
- Deep Learning
